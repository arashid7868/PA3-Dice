# PA3 - Dice

This project is a Python programming assignment for practicing classes, attributes, methods, and random number generation.

## Assignment

Create a class named `DIE` with one attribute called `sides`, which has a default value of 6. The class includes a `roll_die()` method that prints a random number between 1 and the number of sides on the die.

The program:

- Creates a 6-sided die and rolls it 10 times.
- Creates a 10-sided die and rolls it 10 times.
- Creates a 20-sided die and rolls it 10 times.

## How to Run

Make sure Python 3 is installed. Run the program from a terminal with:

```bash
python dice.py
