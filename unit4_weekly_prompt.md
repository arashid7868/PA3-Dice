## Question 5: Describe refactoring and its benefits

Refactoring is the process of making changes to the internal structure and organization of existing computer code, without changing its behavior. That is, the idea is to write code in a fashion that is easier to understand, maintain, test, and change without altering how the code operates. Refactoring, according to Martin Fowler, is "The process of changing the internal structure of software to make it easier to understand and less expensive to modify without changing the observable behavior of the software" (2018). Refactoring may include relatively simple changes that involve renaming variables that are unclear, dividing a long function into smaller ones, eliminating duplicate code, simplifying long conditional statements, or restructuring classes and methods.

A great advantage of refactoring is that it makes the code easier to read. Making code well-structured and with meaningful names makes it easier to understand for the programmer and is easier to work with by others. Well-structured code is easier to maintain when requirements change, thus improving maintainability. Another huge advantage is eliminating redundant code and complexity. If the same reasoning occurs in many locations, then it can be necessary to make changes more than once, which can lead to errors. This logic can be combined and reused in a function or component with refactoring.

Refactoring may also be beneficial in making future development more efficient. Well-structured code will allow developers to easily identify the right place and method to incorporate new features when required. Refactoring is best done in small steps, controlled steps, and steps that don't change the behaviour of the program (Fowler, 2018). Refactoring is not rewriting a program or extending its capabilities; that is why. Rather, it enhances the code quality and structure of already working code.

In summary, refactoring is a crucial technique in programming, as software applications evolve. Refactoring on a regular basis will make the code easier to maintain and develop in the future, and prevent it from getting unnecessarily complicated. Programmers who use Python can make their programs easier to read and more manageable by using techniques like extracting functions, enhancing variable names, eliminating repeating statements, and streamlining logic. So refactoring helps to improve the quality of the code without changing its functionality.
